# OJ课程教案生成技能

根据OJ课程页面的题目列表，自动生成符合项目规范的教案文件。

## 使用场景

- 从OJ新课程页面生成对应课时的教案
- 补充已有课程序列中缺失的课时教案
- 参考现有教案格式，为熟悉度/熟练度练习课编写教案

## 前置条件

1. 已获取OJ课程页面URL（如 `https://oj.example.com/course/xxx`）
2. 已知课程编号和课时编号（如 CSP01-15、CSP04-14）
3. 已有该课程序列的其他课时教案作为格式参考
4. **OJ登录凭据**：从项目根目录的 `.env` 文件中读取 `OJ_USERNAME` 和 `OJ_PASSWORD`，禁止硬编码在脚本中

---

## 工作流程

### 步骤 1：获取课程信息（优先使用工具）

项目已提供解析工具 `tools/course-processing/parse_oj_course.py`，**优先使用它**，避免手动写正则或 curl 命令反复折腾。

```bash
# 默认解析 CSP01 课程并输出 CSP01-15 数据
python tools/course-processing/parse_oj_course.py \
  --course-url https://oj.example.com/course/your_course_id_here \
  --target CSP01-15 \
  --output tools/course-processing/csp15_data.json
```

参数说明：
- `--course-url`：OJ 课程页面 URL
- `--target`：目标课时编号，如 `CSP01-15`
- `--output`：提取结果的 JSON 文件路径
- `--cache`：课程页面 HTML 缓存路径，默认 `tmp/oj_course_page.html`

工具会输出目标课时的完整数据，包括课时标题、`📝 课堂练习`、`📋 课后作业`、`🚀 拓展练习` 三组题目列表。

**curl 备用方案**（仅当工具不可用时使用）：

```bash
# 登录并保存 cookie
curl -sL -c cookies.txt -b cookies.txt \
  -H "User-Agent: Mozilla/5.0" \
  -d "uname=$OJ_USERNAME" \
  -d "password=$OJ_PASSWORD" \
  -d "rememberme=on" \
  -d "login_submit=登录" \
  https://oj.example.com/login

# 获取课程页面
curl -sL -c cookies.txt -b cookies.txt \
  -H "User-Agent: Mozilla/5.0" \
  "https://oj.example.com/course/{course_id}" > course.html
```

### 步骤 2：查找参考教案

1. 确定课程目录：`data/courses/C++/{课程班级名}/`
2. 查看现有教案列表，了解命名格式（如 `01 走进C++.md`、`02 二维数组.md`）
3. **必须读取 2-3 篇与本次主题最相关的现有教案**，掌握格式规范
   - 如果是新知识点课，找知识点相近的教案
   - 如果是熟悉度/熟练度练习课，优先找同类型练习课教案

### 步骤 3：课堂练习分层设计

根据题目特点把课堂练习题分成 2-4 层：

| 分层 | 适用题目 | 设计要点 |
|:---|:---|:---|
| 基础层 | 纯语法、单一循环、直接求和/累乘 | 巩固核心语法，必须附完整参考代码 |
| 进阶层 | 带条件筛选、简单组合、分数/等差数列 | 训练"循环 + 判断"组合思维，附 1-2 道参考代码 |
| 提高层 | 数字特征、数位拆分、多条件计数 | 训练算法思维，附 1 道代表性参考代码 |
| 综合层 | 多条件综合、复杂应用 | 供学有余力的学生挑战，可只列标题 |

**分层原则：**
- 不要平均用力，根据题目实际难度归入合适层级
- 同一层内的题目按从简到难排列
- 参考代码总共选择 **3-5 道** 代表性题目即可
- 其余题目只列题号、题目名、核心训练点

---

### 步骤 4：编写参考代码

- 每道附参考代码的题目必须能直接通过 OJ 测试
- 代码从简到难排列，体现思维递进
- 关键行加注释，但不过度注释
- 注意数据范围：求和/累乘优先使用 `long long`
- 浮点除法必须写成 `1.0 / i`，不能写成 `1 / i`

---

### 步骤 5：提炼高频易错点

从教学经验中提炼 **6-8 条** 真实易错点，例如：

- 求和变量未初始化为 0
- 累乘变量初始化为 0（必须从 1 开始）
- 整数除法丢失小数
- 循环边界搞混（`<=` vs `<`，`>=` vs `>`）
- 数位拆分后原数被修改
- `&&` 和 `||` 逻辑混淆
- 数据类型溢出

---

### 步骤 6：编写课堂总结

使用 `>` 引用格式，包含：
1. 本节课核心内容一句话总结
2. 用 bullet list 回顾 3-5 个关键记忆点
3. 鼓励学生复习错题
4. 预告下节课内容

---

### 步骤 7：保存教案

文件名格式：`{序号} {课时标题}.md`

保存路径：`data/courses/C++/{课程班级名}/`

例如：`data/courses/C++/CSP01示例周六0830/15 熟练度练习-求和计数.md`

保存后通读一遍，检查：
- [ ] 标题格式与现有教案一致
- [ ] 课程目标第一条已加粗
- [ ] 核心知识点条数合理（6-8 条，避免过细拆分）
- [ ] 课堂练习分层清晰
- [ ] 参考代码完整且能运行
- [ ] 高频易错点数量足够
- [ ] 课堂总结为引用格式

---

## 熟悉度/熟练度练习课特殊处理

- 课程目标侧重"巩固"和"熟练运用"，而不是"首次学习"
- 核心知识点以"回顾"形式呈现，条目可以更精炼
- 课堂练习按阶梯分层，不追求全部讲完
- 强调"练成肌肉记忆"
- 课堂总结多鼓励学生重做错题

## 示例：CSP01-15 熟练度练习-求和计数

**分层设计参考：**

| 分层 | 题目 | 说明 |
|:---|:---|:---|
| 基础层 | P1002、P1003、P1004、P1053、P1054 | 连续求和、奇数求和、累乘、等差数列、平方和 |
| 进阶层 | P1014、P1055、P1056、P1057 | 分数求和、条件计数、数位拆分 + 计数、多条件组合计数 |

**参考代码选择：** P1002、P1003、P1053、P1014、P1056、P1057（共 6 道，覆盖两层核心技能）

**高频易错点重点：** 累加器/累乘器初始化、整数除法、循环步长、数位拆分保留原数
