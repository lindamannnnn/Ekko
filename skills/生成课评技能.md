# 生成课评技能

## 技能描述
根据学生信息，自动查找课程目标和生成规则，结合用户提供的本周具体评价，生成符合风格要求的完整课评，并写入学生档案的历史评价部分。

## 工作流程

### 步骤 1：获取课程信息
从用户处得到：
- 学生班级和姓名（确定学生文件路径）
- 本周课程信息（课程类型和课程名称）

### 步骤 2：查找课程目标
- 根据课程类型，在 `data/courses/` 目录中找到对应课程
- 提取课程的教学目标
- 课程目录结构：
  - C++ → `data/courses/C++/CSP01/` 或 `data/courses/C++/CSP04/`
  - Kitten → `data/courses/kitten/乐学课堂/`
  - AI → `data/courses/ai/`（根据实际结构调整）

**C++ 课程文件结构说明：**
- 每个课程文件为 Markdown 格式，命名如 `01 走进C++.md`
- **核心知识点**：从 `## 核心知识点` 部分提取
- **课堂练习**：从 `## 课堂练习` 部分提取具体题目（含题号、题目描述、输入输出格式、参考代码）
- 课后小结中的核心知识点、课程内容均从课程文件中自动提取，无需用户手动输入
- 高频易错点根据课堂练习和学生实际提交数据归纳得出

### 步骤 3：读取生成规则
- 根据课程类型，在 `rules/` 目录中读取对应风格规则：
  - C++ → `rules/c++-style.md`
  - Kitten → `rules/kitten-style.md`
  - AI → `rules/ai-style.md`

### 步骤 4：获取用户评价
用户填写本周学生的具体表现评价（优点、进步、待改进）

### 步骤 5：生成完整课评
- **Kitten/AI**：根据课程类型和规则模板，结合课程目标和用户评价，生成单个学生的课评文本
- **C++**：根据课程类型和规则模板，结合课程目标和用户评价，生成一篇包含全班的**课后小结**（含出勤、核心知识点、高频易错点、课堂整体表现、各娃表现、回家作业清单）
- 严格遵循对应风格的结构和语言要求

### 步骤 6：写入学生文件
将生成的课评追加到学生档案文件 `.claude/memory/class/{班级}/{学生姓名}/profile.md` 的历史评价部分

## 输入要求

### Kitten / AI
用户需要提供：
1. 学生班级
2. 学生姓名
3. 本周课程（课程名称/课时）
4. 本周学生具体表现评价（包含优点、待改进）

### C++
用户需要提供：
1. 班级（CSP01 / CSP04）
2. 本周课程编号（如 CSP05-09）和课程名称
3. 出勤名单和请假名单
4. 各学生的具体表现评价（含题目完成度、OJ提交数据、代码错误类型、学习态度）
5. 回家作业清单（必做/选做）

**自动提取内容（无需用户提供）：**
- 核心知识点 → 从 `data/courses/C++/CSP01/` 或 `CSP04/` 的课程文件中自动提取
- 高频易错点 → 根据课程知识点和课堂练习归纳得出

## 输出要求
1. 先生成完整的课评文本展示给用户确认
2. 用户确认后，再写入学生文件
3. 保持原有学生文件的格式和结构，只追加新的课评

## 格式规范

### Kitten 课评格式（单节课）
```
课程：{班级}
课程主题：{课程名称}
课程内容：
1. {提取自课程文件的教学目标第1条}
2. {提取自课程文件的教学目标第2条}
3. {提取自课程文件的教学目标第3条}
4. {提取自课程文件的教学目标第4条}

{用户提供的本周评价内容}

继续加油！！
```

### C++ 课评格式（周评价 - 课后小结）

**整体结构（一篇课后小结包含全班 + 个人）：**

```
[课程编号] [课程主题] 课后小结

📅 [日期] | 🏫 出勤：[学生名单]
🙋 请假：[学生名单]

📋 【本节课核心知识点】
1. [知识点1] - [掌握程度：必须默写/必须理解/理解即可]
2. [知识点2] - [掌握程度]
...

⚠️ 【高频易错点】
• [易错点1]
• [易错点2]
...

🎯 【课堂整体表现】
[全班整体学习情况总结]

📝 【各娃表现】（亮点+改进）
• [学生A]：[亮点描述]，[具体题号/数据]；[问题描述]，[针对性建议]。
• [学生B]：[亮点描述]，[具体题号/数据]；[问题描述]，[针对性建议]。
...

☑️ 必做：[作业内容]
☐ 选做：[拓展内容]

```

**各娃表现单条格式：**
```
• [学生姓名]：[亮点描述，如思路快/最稳/认真等]，[具体题目完成情况，引用题号]；[问题描述，引用具体错误类型/提交数据]，[针对性建议，可执行]。
```

## 评价平衡原则（重要）

**避免过度夸赞，反映真实状况：**

1. **优点与不足比例**：评价中优点和不足的比例应为 6:4 或 7:3，不要全是表扬
2. **具体问题描述**：
   - 如果学生听课不认真，要具体说明"上课时偶尔会分心，需要老师提醒才能集中注意力"
   - 如果作业完成质量不高，要指出"作业完成得有些匆忙，出现了一些本可以避免的错误"
3. **真实表现记录**：
   - 不要为每个学生都写"表现很棒""进步很大"
   - 表现一般的学生要如实描述："本周表现中规中矩，完成了基本任务，但在主动性方面还有提升空间"
4. **鼓励但不过度**：
   - 保持鼓励的语气，但不要使用"非常优秀""特别出色""超级棒"等过度词汇
   - 改用"有进步""表现不错""值得肯定"等中性偏正面的表达

## 参考评价风格示例

### 示例1（K4 荣熙同学）
课程主题比较有趣，这节课特别积极，听讲的时候非常认真。做程序的时候能够认真先把基础的效果做完，最后还按照自己的想法添加了一些新效果。

### 示例2（K4 小雅同学）
这周的程序有点难度，体现了基本功比较扎实。学到需要多个积木嵌套的时候能够很好地理解程序是如何运行的。做程序时除了用变量修改速度有点难，其他都能很好地完成。

### 示例3（K2 承亨同学）
这节课对于承亨同学还是比较简单的，对于这种比较基础的积木理解起来很快，而且很快就能够自己去运用起来。对于画图形的部分也是能够自己先尝试了，再听老师讲解如何去画出不同的图形，习惯也是比较不错的。

### 示例4（AI01 金小洋同学）- 反映真实情况
本周金小洋同学可能经过了一个星期没来上课，有比较多的知识点有印象，但是具体用来做什么就都忘记了。所以重新按系统性地给他复习了一遍前面的所有内容。后面在讲知识点的时候他说眼睛有点不舒服我们就停下课程让他先休息了，以后记得在上课的前一天戴好眼镜才行。

### 示例5（K4 晟桐同学）- 缺课但跟上节奏
本周的程序是一个综合性非常强的程序，涉及到变量、循环、条件判断的嵌套，知识点用得比较多，也比较难。晟桐同学本周表现也是不错的噢，虽然这个单元有几节课没来上，而且本周的程序也是比较难的，但是他也是能够跟上节奏，看着流程图一步步去完成出程序的效果的，逻辑思维还是比较清晰的，能知道每一步需要做什么，非常不错的，继续加油！！

### 示例6（K4 小雅同学）- 基础扎实
本周的程序是一个综合性非常强的程序，涉及到变量、循环、条件判断的嵌套，知识点用得比较多，也比较难。小雅同学属于基础比较好的，这些比较难的程序对于她来说也是完全没有什么问题。做的时候思路也是非常清晰能够知道每一步需要去做什么的，继续加油吧！！

### 示例7（K4 小轩同学）- 指出问题（重要参考）
本周的程序是一个综合性非常强的程序，涉及到变量、循环、条件判断的嵌套，知识点用得比较多，也比较难。小轩同学之前说过有些基础的知识点掌握得不太牢固的问题在这个程序会比较能体现出来，单独的新讲的知识点在当节课的运用他是能够跟得上的，在这个需要用到非常多以前的旧知识点的综合程序对于他来讲就有点跟不上了。上课需要更加认真注意去听才行，要是看到有忘记怎么做的效果，要及时提问，而不是自己去尝试做一些奇奇怪怪的效果。

### 示例9（K2 小宸同学）- 缺课但学得快

## 写作风格要点

从以上示例可以看出，好的课评应该：

1. **说明难度感受** - "这节课对于承亨同学还是比较简单的"
2. **具体行为描述** - "除了用变量修改速度有点难到她了"
3. **真实问题反映** - "知识点有印象，但具体用来做什么都忘记了"
4. **给出具体建议** - "以后记得在上课的前一天戴好眼镜才行"
5. **口语化表达** - "这节课特别积极""习惯也是比较不错的"

**参考评价结构（约200-300字）：**
- 开头：说明课程难度或学生整体状态（20%）
- 优点：具体说明做得好的地方，用具体行为支撑（30-40%）
- 不足：客观指出需要改进的地方，具体说明（30-40%）
- 建议：给出针对性的建议或提醒（10-20%）
- 结尾：鼓励性结束语（继续加油！！）

## 如何参考示例写作（重要）

生成课评时，**优先参考 `references/teacher-style/KITTEN.md` 中的课评示例**（已有14个真实课评），模仿其中的语言风格、句式结构和表达方式：

### 1. 开头方式（参考示例1、2、3）
- 说明课程难度感受："这节课对于承亨同学还是比较简单的"
- 说明学生状态："可能是因为课程主题也是比较有趣的，这次的课特别积极"
- 说明知识点掌握："这就体现了小雅同学的基本功比较扎实"

### 2. 具体表现描述（参考示例2、3、4）
- 具体行为："除了用变量修改速度有点难到她了以后其他的程序都能很好地完成出来"
- 学习习惯："对于画图形的部分也是能够自己先尝试了，再听老师讲解"
- 真实情况："本周金小洋同学可能经过了一个星期没来上课，有比较多的知识点有印象，但是具体用来做什么就都忘记了"

### 3. 结尾方式（统一风格）
- 使用"继续加油！！"或"继续加油噢！！"结尾
- 可以用"非常不错的""很不错的"作为过渡

### 4. 语气词汇（参考所有示例）
- 使用"噢""吧""呢"等语气词
- 使用"也是比较""还是比较""非常""比较"等程度词
- 使用"能够""可以""有点""比较"等客观描述词

### 5. 禁止事项
- 不要使用"非常优秀""特别出色""超级棒""极其出色"等过度夸张的词汇
- 不要每个课评都写"表现非常棒""进步很大"
- 不要编造学生没有的行为

## 注意事项
- 必须从 `data/courses/` 中的课程文件提取教学目标，不能编造
- 必须严格遵循 `rules/` 中对应课程的风格要求
- **优先参考本文件中的示例风格，这是老师的实际写作风格**
- 只追加新课评，不删除或修改历史评价
- 如果找不到课程文件，及时告知用户
