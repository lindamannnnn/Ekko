## 构建指引（Step 3）

### 听说课

| 环节 | 时间 | 教学活动 |
|------|------|----------|
| Warm-up | 3-5 分钟 | 歌曲/游戏/自由对话，激活已有知识 |
| Presentation | 8-10 分钟 | 呈现新语言材料（对话/图片/短句），感知理解 |
| Practice | 10-12 分钟 | 控制性操练（机械替换→半开放句子），Pair work |
| Production | 8-10 分钟 | 真实情境中的自由输出，Role play / Interview |
| Summary & Assessment | 3-5 分钟 | 归纳要点，课堂小测 |

### 读写课

| 环节 | 时间 | 教学活动 |
|------|------|----------|
| Pre-reading | 5 分钟 | 预测内容、激活背景知识 |
| While-reading | 12 分钟 | 阅读获取信息（skimming → scanning → close reading） |
| Post-reading | 8 分钟 | 理解检测、讨论、语言点学习 |
| Writing | 8-10 分钟 | 仿写/续写/改写（提供句型支架） |
| Sharing & Assessment | 3-5 分钟 | 分享作品，课堂小测 |

### 语音/语法课

| 环节 | 时间 | 教学活动 |
|------|------|----------|
| 发现感知 | 5-8 分钟 | 在语境中呈现目标语音/语法现象 |
| 归纳规则 | 5-8 分钟 | 引导学生发现规律，教师补充 |
| 控制练习 | 10 分钟 | 机械性操练（辨音/替换/连线） |
| 运用产出 | 8-10 分钟 | 在情境中运用目标项目 |
| 课堂小测 | 3-5 分钟 | 检测掌握情况 |

### 学段分级指导

| 学段 | 教学重点 | 课堂用语 | 输出要求 |
|------|----------|----------|----------|
| 小学 3-4 年级 | 听说为主，简单读写，培养兴趣 | 英语为主，必要时中文辅助 | 词/短语/简单句 |
| 小学 5-6 年级 | 听说读写全面发展，简单语法意识 | 英语为主 | 短段落 |
| 初中 7-9 年级 | 系统语法，阅读策略，语篇意识 | 全英语 | 段落/短文 |
| 高中 10-12 年级 | 学术阅读，议论文写作，跨文化交际 | 全英语 | 较长语篇 |

### 英语课特有脚手架

| 类型 | 说明 |
|------|------|
| **句型框架** | 提供目标句型的填空/替换框架，如"I like ____ because ____" |
| **对话模板** | 示范对话 + 替换关键词，学生 pair work 使用 |
| **词汇图** | 主题词汇分类图（如"食物"→水果/饮料/主食） |
| **语音支架** | 发音口型图、音节拆分、重音标记 |
| **Pair work 引导** | 明确 A/B 角色分工 + 轮换指令 |
| **写作模板** | 段落结构框架（Topic sentence → Supporting details → Conclusion） |
| **思维导图** | 帮助学生组织写作或口语输出内容 |

### 课堂小测形式

- **听力检测：** 听选图片/听选信息/听写单词
- **口语检测：** 看图说话 / Pair work 展示 / 简短问答
- **读写检测：** 补全句子 / 阅读选择 / 仿写段落
- **词汇/语法：** 填空 / 连词成句 / 改错

### 注意事项

- **英语授课比例：** 小学英语课堂英语使用率 ≥ 70%，初中 ≥ 90%，高中全英语
- **Pair work / Group work：** 每节课至少有一次学生间互动活动
- **情境真实：** 语言操练应嵌入真实交际情境，避免机械孤立操练
- **文化意识：** 适当介绍英语国家文化背景，培养跨文化理解
- **分层设计：** 低层提供更多句型支架和词汇提示，高层减少支架增加输出长度

## lesson.json 映射

- `shared.subject`: `"英语"`
- `shared.domain`: 听说/读写/语音/语法/综合
- `shared.topic`: 主题语境（人与自我/人与社会/人与自然）

**文档结构：**
| id | audience | 内容 |
|----|----------|------|
| `lesson_plan` | 教师 | 上述环节 + 材料清单 + 板书 + 句型/词汇 + Pair work 指令 |
| `student_materials` | 学生 | 对话模板 / 阅读材料 / 练习单 + 句型框架 |
| `observation_template` | 教师 | 语言能力观察点 + Pair work 参与度 + 课堂小测分类 |

**shared 常用注册内容：** 核心句型、对话模板、阅读材料、词汇表、写作框架、Pair work 指令。
