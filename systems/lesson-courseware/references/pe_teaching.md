# 体育与健康 — 课时教案模板

Loaded by `k12-lesson-planning` when the subject is **pe**（体育与健康）.

## 澄清优先级（Step 1）

1. **年级 + 运动项目**（球类/田径/体操/游泳/冰雪/民族传统体育/体能）
2. **课时目标**（技能学练 / 体能训练 / 健康知识 / 体测）
3. **课标要求**（未提供时 Step 2 从 `pe.md` + `pe_topics.md` 提取）
4. **场地与器材**（确认可用场地和器材，影响活动设计）

**默认值：** 未指定时长 → 40 分钟。未指定场地 → 默认学校操场/体育馆。

## 构建指引（Step 3）

### 技能学练课（主要课型）

| 环节 | 时间 | 教学活动 |
|------|------|----------|
| 课堂常规 | 2 分钟 | 整队、检查着装、宣布内容、安排见习生 |
| 准备活动 | 5-8 分钟 | 热身跑 + 专项准备活动（动态拉伸/动作准备） |
| 技能学练 | 15-18 分钟 | 示范→分解练习→完整练习→纠错指导 |
| 巩固提高 | 8-10 分钟 | 组合练习或简化比赛 |
| 体能练习 | 5 分钟 | 一般体能或专项体能（如折返跑、核心力量） |
| 放松小结 | 3-5 分钟 | 静态拉伸 + 课堂小结 + 回收器材 |

### 体能训练课

| 环节 | 时间 | 教学活动 |
|------|------|----------|
| 准备活动 | 5-8 分钟 | 热身 + 动态拉伸 |
| 主训练 | 20 分钟 | 循环训练/间歇训练/分组轮换 |
| 核心/补偿 | 5-8 分钟 | 薄弱环节强化 |
| 放松小结 | 3-5 分钟 | 拉伸 + 数据记录 + 小结 |

### 不适配场景

| 课时类型 | 处理方式 |
|----------|----------|
| **体测课** | 所有学生完成相同测试项目。低层提供规则解释和动作示范；高层增加自评/互评和数据分析。 |
| **健康知识课**（室内理论） | 参考语文阅读/讨论结构。环节：情境导入→知识探究→小组讨论→实践应用→小测。 |
| **队列队形练习** | 低层单一动作练习；中层组合变换；高层指挥/创编队列。 |

### 学段分级指导

| 学段 | 教学重点 | 运动密度要求 | 技能要求 |
|------|----------|-------------|----------|
| 小学 1-2 年级 | 基本运动技能（移动/操控/稳定），情境化游戏为主 | ≥ 75% | 体验为主，不强调技术规范 |
| 小学 3-6 年级 | 专项运动技能入门，体能练习，健康教育 | ≥ 75% | 初步掌握基本技术 |
| 初中 7-9 年级 | 专项运动技能系统学习，体能系统训练 | ≥ 75% | 掌握 1-2 项运动的基本技战术 |
| 高中 10-12 年级 | 专项化发展，运动技能运用，健康行为养成 | ≥ 75% | 较熟练掌握至少 1 项运动 |

### 体育课特有脚手架

| 类型 | 说明 |
|------|------|
| **动作口诀** | 将技术要点编成简短口诀（如"蹬地→转体→挥臂"），辅助记忆 |
| **任务卡** | 图文结合的动作要领卡，分组练习时自助参考 |
| **分层标志** | 不同距离/高度/难度的练习标志线，学生自主选择起点 |
| **同伴观察** | 两人一组交替练习与观察，用简单标准互评（如"同伴的手是否伸直"） |
| **视频反馈** | 录制动作后回看，与示范动作对比 |
| **简化规则** | 降低原版比赛规则复杂度，让更多学生参与（如缩小场地/减少人数） |

### 课堂小测形式

体育课的课堂小测不同于学科课，可采用：

- **技能检测：** 连续垫球 X 次、运球绕杆计时、立定跳远成绩
- **口头问答：** 运动规则、安全知识、健康知识
- **自评/互评：** 对照标准给自己的动作打分，或评价同伴动作
- **练习记录：** 完成规定次数的练习后签字确认

### 注意事项

- **安全第一：** 每个技能练习前说明保护与帮助方法；检查场地器材安全
- **运动密度 ≥ 75%：** 学生实际运动时间/总课时，减少讲解和等待时间
- **关注个体差异：** 允许不同起点、不同进步速度；分层设置练习难度
- **天气预案：** 雨天/雾霾/高温等极端天气时准备室内替代方案或理论学习
- **场地器材：** 课前确认器材数量和场地布局，写在教案材料清单中

## lesson.json 映射

- `shared.subject`: `"体育与健康"`
- `shared.sport`: 运动项目名称
- `shared.equipment`: 器材清单

**文档结构：**
| id | audience | 内容 |
|----|----------|------|
| `lesson_plan` | 教师 | 上述环节 + 材料清单 + 动作要领 + 安全提示 + 场地布置 |
| `observation_template` | 教师 | 技能掌握观察点 + 运动密度记录 + 安全情况 |
| `student_materials` | 学生 | 动作图解 + 练习记录表 + 自评表（仅室内/理论课时需要） |

**shared 常用注册内容：** 动作要领、练习记录卡、安全须知、自评标准、场地布置图。
