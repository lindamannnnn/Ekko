# 数学 — 课时教案模板

Loaded by `k12-lesson-planning` when the subject is **math**（数学）.

## 澄清优先级（Step 1）

在提问之前，从所有可用的对话信号中评估以下信息：

**1. 年级检测** 扫描对话中的年级信号。如果已明确，使用该年级；如果缺失，优先询问。

**2. 教材版本检测。** 扫描教师是否提及教材版本（人教版/北师大版/苏教版/华师大版等）。如果明确，在输出中参考该版本的单元编排与例题风格（仅用于举例风格，不加载教材数据）。如果未提及，使用国家课标通用要求。

**3. 知识点检测。** 从教师表述中提取核心数学知识点（如分数乘法、方程、圆面积等）。

当关键信息缺失时按优先级询问：(1) 年级，(2) 具体知识点，(3) 教材版本（如不可推断）。其余信息静默使用默认值：时长 40 分钟（小学）/ 45 分钟（初中/高中），应用 UDL 中国默认值（句子支架 + 词汇表）。

## 构建指引（Step 3）

### 课时环节（通用结构）

| 环节 | 时间 | 教学活动 |
|------|------|----------|
| 导入 | 5-8 分钟 | 从生活情境或已有知识引出问题 |
| 探究 | 12-15 分钟 | 操作/画图/推理，发现规律或建构概念 |
| 练习 | 10-12 分钟 | 层次性练习（基础→变式→拓展） |
| 小结 | 3-5 分钟 | 梳理方法、联系旧知 |
| 课堂小测 | 3-5 分钟 | 检测掌握情况 |

### 课型变体

**计算/概念课：** 情境引入 → 探究算理/概念 → 归纳方法 → 巩固练习 → 课堂小测
**几何/测量课：** 操作感知 → 抽象概括（归纳公式/性质）→ 应用迁移 → 拓展延伸 → 小结检测
**统计/概率课：** 问题驱动 → 数据收集 → 分析与推断 → 交流质疑 → 课堂小测

### 练习设计要求

**结构覆盖 — 必要而非可选。** 在编写练习之前，枚举课标要求的所有结构类型——从基线情形（每个学生必须掌握）到结构上最困难的情形（学生最常出错的情形）。然后编写题组，使每种枚举的结构类型都作为编号的必要习题出现。

覆盖规则：
- 只在引导语或教师提示中出现、没有对应编号习题的结构类型，不计为已覆盖。
- 强调最困难的情形不意味着可以省略基线情形：全难题组和全易题组同样不达标。
- 如果课标涉及有理数，至少一道必要习题使用分数或小数——纯整数组不覆盖。
- 从不将必要的结构类型移至选做拓展题——如果只作为附加题出现，大多数学生从未接触。

### 数学特有脚手架

**概念 → 主要视觉模型：**

| 数学概念类型 | 主要视觉模型 |
|--------------|------------|
| 部分-整体 / 加法推理 | 线段图或部分-整体图 |
| 乘法 / 比 / 比例推理 | 双数线或比例表 |
| 作为数轴上的量的分数 | 数轴 |
| 面积 / 乘法结构 | 面积模型或阵列 |
| 比例关系 / 线性函数 | 数值表或坐标图 |
| 代数结构 / 方程推理 | 方程平衡模型或变量表示 |
| 几何关系 | 标注图，带注释 |

**CRA 递进框架：**

| 层级 | CRA 切入点 |
|------|-----------|
| 低层 | 具象（学具或实物模型）→ 表象（图示、视觉模型） |
| 中层 | 表象 → 抽象（符号化、数字化） |
| 高层 | 抽象 → 联系（概括、结构洞察、前向标准） |

### 注意事项

- 数学概念教学应经历具体→半抽象→抽象的过程
- 计算课关注算理与算法的平衡，避免只练算法不重算理
- 练习题按"基础→变式→拓展"梯度设计
- 落实"双减"：作业分层设计，小学 1-2 年级无书面家庭作业，3-6 年级书面作业 ≤ 60 分钟

## 课堂小测指引

课堂小测是课时最后环节（`from_shared:exit_ticket`）。

- 它必须是**结构上最困难的情形**（摘自上述习题枚举），而非中等难度的替代题。选择标准：持有本课主要迷思概念的学生必须答错该题。如果持有迷思概念的学生也能答对，说明你选了一个肯定性实例——换成区分性实例。
- **验证课堂小测和每个答案：** 实际计算一遍——声明的答案必须是题目实际产生的结果。
- 3 个分类等级——**掌握 / 基本掌握 / 需重新教学**——**每个都有明确标准**描述落在该等级的答案特征（例如"掌握：方程正确，未知数位置与故事匹配"，而非仅有标签）。

## lesson.json 映射

- `shared.subject`: `"数学"`
- `shared.domain`: 数与代数/图形与几何/统计与概率/综合与实践
- `shared.p1`..`pN`: 每道练习作为一个独立 key，`{student: <题目文本>}`，可选 `teacher` 分面描述观察要点
- `shared.exit_ticket`: `{student: <题目——新题，非练习重复>, teacher: <收集说明>}`

**文档结构：**
| id | audience | 内容 |
|----|----------|------|
| `lesson_plan` | 教师 | 上述环节 + 材料清单 + 板书 + 题组 + 常见错误 + 设计说明 |
| `student_materials` | 学生 | 练习题单 + 操作图/几何模板 |
| `observation_template` | 教师 | 算理理解观察点 + 典型错例 + 课堂小测分类 |

**shared 常用注册内容：** 驱动情境、例题、练习题组、视觉模型、操作指南、常见错例。
