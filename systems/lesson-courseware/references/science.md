# 科学 — 课时教案模板

Loaded by `k12-lesson-planning` when the subject is **science**（科学/物理/化学/生物）。

## 澄清优先级（Step 1）

在提问之前，从所有可用的对话信号中评估以下信息：

**1. 年级与学科方向。** 确定年级和学科方向（小学科学 / 物理 / 化学 / 生物学）。不同学科方向对应不同的课标文件。

**2. 核心概念。** 从教师表述中提取核心概念（如物质变化、力与运动、生态系统等）。

**3. 学段特征。** 根据年级确定学段特征：
- **小学 1-2 年级：** 以具体现象为主，教师引导的 sense-making，口头和图画模型
- **小学 3-6 年级：** 过渡期——开始书面解释，机械论模型，简单数据分析
- **初中 7-9 年级：** 跨学科整合，定量推理，正式论证
- **高中 10-12 年级：** 数学建模，拓展探究，社会/伦理维度

当关键信息缺失时按优先级询问：(1) 年级，(2) 具体知识点或课标要求，(3) 学科方向（如不明确）。其余信息静默使用默认值：时长 40 分钟（小学）/ 45 分钟（初中/高中），应用 UDL 中国默认值。

## 构建指引（Step 3）

### 通用课时结构

| 环节 | 时间 | 教学活动 |
|------|------|----------|
| 聚焦现象 | 5-8 分钟 | 呈现可观察的现象或问题，不解释原因 |
| 探究实践 | 15-20 分钟 | 实验/观察/查阅资料，收集证据 |
| 研讨建构 | 8-12 分钟 | 分析证据、形成解释、交流论证 |
| 模型/表征 | 5-8 分钟 | 用图画/图表/模型呈现理解 |
| 课堂小测 | 3-5 分钟 | 检测概念理解 |

### 课型变体

**实验探究课：** 提出问题 → 猜想假设 → 实验验证 → 分析结论 → 交流拓展
**观察/认识课：** 聚焦现象 → 系统观察 → 整理归纳 → 应用迁移 → 课堂小测
**工程实践课：** 明确需求 → 设计方案 → 制作测试 → 优化改进 → 展示评价

### 学段注意事项

**小学 1-2 年级：**
- 现象必须可直接观察——不把视频作为主要引入方式
- 探究先于解释——学生先收集数据，教师不在探究前解释现象
- 模型以图画为主要表征形式

**小学 3-6 年级：**
- 每节探究课都应包含书面解释（主张-证据-推理）
- 模型必须有机制——能显示"如何"和"为什么"，而不仅是标注

**初中 7-9 年级：**
- 数据涉及定量时，学生必须使用数据而非仅定性描述
- 论证需要来自实验的证据，而非已有知识
- 跨学科概念（物质与能量、系统与模型、因果等）应被学生显式使用

**高中 10-12 年级：**
- 数学建模是解释工具，而非装饰——学生须解释每个变量代表什么
- 科学不确定性应被显式承认——哪些仍未知
- 科学-社会联系应要求学生从科学推理到社会/伦理含义

### 科学课特有脚手架

- **图画模型：** "画出你认为正在发生什么。标出你能看到的和你推断的。"
- **主张-证据-推理框架：** "我的主张是____。我的证据是____。这支持我的主张因为____。"
- **预测-观察-解释：** "预测会发生什么→观察实际→解释差异"
- **比较表：** 整理不同组实验数据，寻找模式
- **概念图：** 展示概念之间的因果关系

### 注意事项

- "猜想"环节要区分"有依据的推测"和"随意猜测"
- 数据记录单应预设计录框架（表格/图示），降低记录门槛
- 安全提示在所有实验环节中不可省略
- 落实"双减"：科学课以课堂探究为主，课外不布置书面作业

## lesson.json 映射

- `shared.subject`: `"科学"` / `"物理"` / `"化学"` / `"生物学"`
- `shared.domain`: 物质科学/生命科学/地球与宇宙/技术与工程
- `shared.anchor_task`: 驱动现象——`{teacher: <如何呈现不解释>, student: <学生观察/操作>}`
- `shared.t1`..`tN`: 每项探究任务独立 key，`{teacher: <引导脚本>, student: <任务文本>}`

**文档结构：**
| id | audience | 内容 |
|----|----------|------|
| `lesson_plan` | 教师 | 上述环节 + 材料清单 + 实验步骤 + 安全提示 + 常见迷思 |
| `student_materials` | 学生 | 实验记录单 + 数据表 + 安全须知 |
| `observation_template` | 教师 | 实验操作观察点 + 数据记录评价 + 课堂小测分类 |

**shared 常用注册内容：** 驱动问题、实验步骤、数据记录表、图画模型模板、安全须知、常见迷思。
