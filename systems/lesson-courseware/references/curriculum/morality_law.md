# 义务教育道德与法治课程标准（2022年版）

依据：教育部教材〔2022〕2号
PDF: `raw/curriculum-2022/02-道德与法治.pdf`

## 课程性质
道德与法治课程是义务教育阶段的思政课程，旨在提升学生思想政治素质、道德修养、法治素养和人格修养。

## 核心素养（5个方面）

| 核心素养 | 内涵 |
|---------|------|
| **政治认同** | 拥护党的领导，认同社会主义核心价值观，坚定中国特色社会主义道路自信 |
| **道德修养** | 养成良好的社会公德、职业道德、家庭美德、个人品德 |
| **法治观念** | 尊法学法守法用法，具备依法维护自身权益、参与社会生活的意识和能力 |
| **健全人格** | 具有积极的心理品质、自尊自信、理性平和、积极向上的心态 |
| **责任意识** | 具有主人翁意识、担当精神，积极参与社会实践 |

## 课程内容（学段划分）

| 学段 | 年级 | 重点主题 |
|------|------|---------|
| 第一学段 | 1-2年级 | 道德启蒙、规则意识、爱祖国爱集体 |
| 第二学段 | 3-4年级 | 社会公德、集体生活、基本法律常识 |
| 第三学段 | 5-6年级 | 国家认同、宪法常识、中华优秀传统文化 |
| 第四学段 | 7-9年级 | 法治教育、国情教育、责任担当 |

## 主要学习主题领域
- 道德教育：个人品德、家庭美德、社会公德
- 法治教育：宪法教育、民法典常识、未成年人保护
- 国情教育：国家领土、民族团结、中华文化
- 心理健康：自我认识、情绪管理、人际交往
- 社会责任：志愿服务、公共参与、国际视野

## 学业质量
- **水平一**（小学低段）：能分辨基本是非，遵守规则，表达爱国情感
- **水平二**（小学高段）：理解基本法律常识，形成初步的道德判断能力
- **水平三**（初中）：运用法治思维分析问题，具有社会责任感
