## 基础模块

基础模块教学内容由主题、语篇类型、语言知识、文化知识、语言技能、语言策略六部分构成。

### 1. 主题

**内容要求：**

基础模块包括人与自我、人与社会和人与自然三大主题范围，涵盖 8 个主题：

| 主题范围 | 主题 | 内容要点 |
|----------|------|----------|
| 人与自我 | 主题1 自我与他人 | 个人信息、兴趣爱好、情感态度、学习与生活 |
| 人与社会 | 主题2 家庭与社区 | 家庭关系、社区生活、人际交往 |
| 人与社会 | 主题3 日常生活 | 购物、饮食、服装、节日、庆典 |
| 人与社会 | 主题4 健康与保健 | 体育运动、疾病预防、健康饮食、急救 |
| 人与社会 | 主题5 交通与旅游 | 交通工具、问路指路、旅行安排、景点介绍 |
| 人与社会 | 主题6 科学与技术 | 发明创造、信息技术、网络应用、科技发展 |
| 人与自然 | 主题7 自然环境 | 天气气候、环境保护、自然灾害、生态平衡 |
| 人与社会 | 主题8 工作与职业 | 职业理想、求职应聘、职场礼仪、职业规划 |

**相关领域：**
- 基础模块·主题（三大主题范围 8 个主题）

### 2. 语篇类型

**内容要求：**

语篇类型包括记叙文、说明文、应用文和议论文等不同文体，以及口头、书面等语体。

| 类别 | 语篇类型 |
|------|----------|
| 记叙文 | 个人故事、新闻报道、传记、游记 |
| 说明文 | 科普文章、产品说明、操作指南 |
| 应用文 | 书信、邮件、通知、海报、简历、广告 |
| 议论文 | 社论、评论、观点论述 |
| 口头语篇 | 对话、访谈、演讲、指令 |
| 新媒体语篇 | 社交媒体、博客、网页 |

**相关领域：**
- 基础模块·语篇类型

### 3. 语言知识

#### （1）语音知识

**内容要求：**

语音知识包括音标、重音、语调、节奏、连读等内容。

- 26 个字母读音
- 英语国际音标符号读音
- 基本元音和辅音读音
- 单词的基本读音规则
- 单词重音和句子重音
- 连读和失去爆破
- 语调、节奏与韵律

**相关领域：**
- 基础模块·语音知识

#### （2）词汇知识

**内容要求：**

基础模块词汇量约 2490 词（含义务教育阶段），另设参考词汇表约 141 词（包括大洲、大洋、国家、语言、月份、数词、星期、中国传统文化词汇等）。

**相关领域：**
- 基础模块·词汇知识

#### （3）语法知识

**内容要求：**

包括词类（名词、代词、数词、介词、冠词、连词、形容词、副词、动词、感叹词）、构词法（合成、派生、转化）、句法（时态 8 种、被动语态、非谓语动词、句子种类、简单句基本句型、直接引语与间接引语、并列复合句、主从复合句、主谓一致、强调、倒装、省略、虚拟语气）。

**相关领域：**
- 基础模块·语法知识

#### （4）语篇知识

**内容要求：**

了解不同语篇结构，关注语篇意义，加深对语篇的理解，选择恰当的语篇类型进行表达与交流。

**相关领域：**
- 基础模块·语篇知识

#### （5）语用知识

**内容要求：**

了解常见语言表达形式的语用功能，能够根据交际目的、对象、场合不同选择适当的表达方式，实现有效交际。

**交际功能包括：** 问候与道别、引荐与介绍、感谢与道歉、预约与邀请、祝愿与祝贺、求助与提供帮助、赞同与反对、接受与拒绝、询问与提供信息、投诉与责备、表扬与鼓励、指令与要求、禁止与警告、劝告与建议、情感表达、价格商议等。

**相关领域：**
- 基础模块·语用知识

### 4. 文化知识

**内容要求：**

文化知识包括中外文化知识和职场文化知识。学生应了解中外文化习俗、职场文化和中外优秀企业文化，能够用英语表述中华优秀传统文化、革命文化和社会主义先进文化，讲述中国故事。

**相关领域：**
- 基础模块·文化知识

### 5. 语言技能

**内容要求：**

| 技能 | 要求 |
|------|------|
| 听 | 能听懂日常生活和职场场景中的简单对话和叙述，能根据语气和语调判断态度 |
| 说 | 能进行简单的日常交流，能围绕熟悉话题进行简短陈述，语音语调基本正确 |
| 读 | 能理解常见语篇的主旨大意和关键信息，能根据上下文推断词义 |
| 写 | 能写出简单的记叙文、说明文和应用文，格式规范、语言基本准确 |

**相关领域：**
- 基础模块·语言技能

### 6. 语言策略

**内容要求：**

语言策略包括语言学习策略和语言技能发展策略。

| 策略类型 | 内容 |
|----------|------|
| 元认知策略 | 计划、监控、评价、反思和调整学习过程 |
| 认知策略 | 为完成具体学习活动采取的步骤和方法 |
| 交际策略 | 争取交际机会、维持交际、提高交际效果 |
| 情感策略 | 调控学习情绪、保持积极学习态度 |
| 理解策略 | 信息获取中的规划、执行、评估和补救 |
| 表达策略 | 中介语交际、计划、补偿和监控 |
| 交互策略 | 寻求澄清、规划、修补误解 |

**相关领域：**
- 基础模块·语言策略

## 职业模块

职业模块依据与职业领域相关的通用职场能力设立 8 个主题，学时 36 学时。

**主题范围：**

| 主题 | 说明 |
|------|------|
| 求职应聘 | 简历、面试、求职信、自我介绍 |
| 职场礼仪 | 着装、行为规范、沟通礼仪 |
| 办公事务 | 电话、邮件、会议、日程安排 |
| 客户服务 | 接待、咨询、投诉处理 |
| 产品与业务 | 产品介绍、业务洽谈、营销推广 |
| 行业英语 | 与专业相关的英语术语和表达 |
| 企业文化 | 中外企业文化比较 |
| 职业规划 | 职业发展、终身学习 |

**语言知识补充：** 继续学习 200 个左右词汇，巩固语音、语法、语篇和语用知识。

---

## 拓展模块

拓展模块为任意选修内容，满足学生继续学习和个性发展需要，在完成基础模块后开设，学时不作统一规定。

## 学科核心素养

| 核心素养 | 内涵 |
|---------|------|
| **职场语言沟通** | 通过英语语言知识的学习与实践，掌握语言特点及其运用规律，发展听、说、读、写等语言技能，正确理解职场中不同类型的语篇信息，就与职业相关的话题进行有效沟通与交流。 |
| **思维差异感知** | 通过观察、分析、比较等方式，认识口头交流与书面交流的表达特点，感知不同文化背景下思维方式的多样性，理解中西方思维方式的差异，从不同视角观察和认识世界。 |
| **跨文化理解** | 通过学习中外优秀文化，拓宽国际视野，形成对外国文化的正确认识、对中华优秀文化的深刻认知及对中外企业文化的客观了解，以开放包容的心态理解多元文化，坚定文化自信，促进文化传播。 |
| **自主学习** | 根据自身特点，制定学习方案，选择和运用恰当的学习策略，养成良好的学习习惯，促进语言学习与学习能力的可持续发展。 |
