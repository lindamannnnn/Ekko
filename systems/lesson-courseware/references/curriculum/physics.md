# 义务教育物理课程标准（2022年版）

依据：教育部教材〔2022〕2号 | PDF: `raw/curriculum-2022/09-物理.pdf`

## 核心素养（4个方面）

| 核心素养 | 内涵 |
|---------|------|
| **物理观念** | 物质观、运动与相互作用观、能量观等 |
| **科学思维** | 模型建构、科学推理、科学论证、质疑创新 |
| **科学探究** | 提出问题、猜想假设、设计实验、分析论证、评估反思 |
| **科学态度与责任** | 科学态度、社会责任、科技伦理 |

## 内容五大主题

1. **物质** — 物质的形态和变化、物质的属性、物质的结构和物质世界的尺度
2. **运动和相互作用** — 多种多样的运动形式、机械运动和力、声和光、电和磁
3. **能量** — 能量转化和转移、机械能、内能、电磁能、能量守恒、能源与可持续发展
4. **实验探究** — 测量类必做实验（9个）、探究类必做实验（12个）
5. **跨学科实践** — 物理学与日常生活、物理学与工程实践、物理学与社会发展

## 学段
八年级和九年级开设

## 学业质量

**学业质量内涵：** 学业质量是学生在完成课程阶段性学习后的学业成就表现，反映核心素养要求。

**学业质量描述：** 能认识物质的形态、属性及结构，认识运动和力、声和光、电和磁，认识机械能、内能、电磁能及能量的转化与守恒；在熟悉情境中运用物理模型分析实际问题；能发现并提出探究问题，运用控制变量法等制订探究方案；初步认识科学本质，具有科学态度和责任感。

完整学业质量标准见 `references/curriculum/fulltext/义务教育-09-物理.md`。
