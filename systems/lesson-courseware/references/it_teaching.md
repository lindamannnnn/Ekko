## 构建指引（Step 3）

### 通用课时结构

| 环节 | 时间 | 教学活动 |
|------|------|----------|
| 情境引入 | 5 分钟 | 真实问题或生活场景导入，激发兴趣 |
| 问题分析 | 8 分钟 | 分解问题、分析需求、提取关键要素 |
| 方案设计 | 8-10 分钟 | 算法设计/流程图/方案规划 |
| 实践验证 | 12-15 分钟 | 编程实现/操作验证/调试优化 |
| 总结拓展 | 3-5 分钟 | 梳理收获、迁移思考、安全意识 |

### 课型变体

**编程课：** 情境引入 → 算法设计 → 编程实现 → 调试优化 → 分享展示
**网络/安全课：** 情境体验 → 原理探究 → 实践操作 → 案例分析 → 安全意识
**数据处理课：** 问题驱动 → 数据收集 → 整理分析 → 可视化呈现 → 结论交流
**AI 课：** 体验感知 → 原理浅析 → 应用探究 → 伦理讨论 → 创意设计
**物联网课：** 场景感知 → 系统搭建 → 数据采集 → 反馈控制 → 拓展思考

### 学段分级指导

| 学段 | 学习重点 | 编程工具 | 教学策略 |
|------|----------|----------|----------|
| 小学 3-4 年级 | 信息交流与分享、数字作品创作、在线安全 | 图形化（Scratch JR/Scratch） | 积木拖拽，模仿→改造→创作 |
| 小学 5-6 年级 | 算法初步、数据组织、编程基础 | Scratch / Python 入门 | 半成品代码→完整程序→自主创作 |
| 初中 7-9 年级 | 互联网原理、物联网、人工智能、数据处理 | Python / 图形化编程 | 问题驱动，项目式学习 |
| 高中 10-12 年级 | 算法与程序设计、信息系统、人工智能基础 | Python / 伪代码 | 抽象建模，真实问题求解 |

> 注：义务教育阶段信息科技课从 3 年级开始独立开设，1-2 年级不单设信息科技课。

### 信息科技特有脚手架

| 类型 | 说明 |
|------|------|
| **半成品代码** | 提供程序框架，学生填充核心逻辑。适用于新概念引入阶段 |
| **步骤卡片** | 排序好的操作步骤卡（可打乱，学生排序后执行） |
| **调试引导** | 分步提示：① 检查语法 → ② 检查条件 → ③ 检查循环边界 → ④ 检查变量值 |
| **输出对照** | 给定期望输出，学生对照调试代码 |
| **概念类比** | "变量就像带标签的盒子""循环就像绕操场跑圈" |
| **结对编程** | 两人一组："驾驶员"写代码，"导航员"读代码、检查错误、思考下一步 |
| **流程图模板** | 预置流程符号的半成品流程图，学生补充逻辑 |
| **常见错误库** | 该任务中学生最常犯的 3 个错误 + 修正提示 |

### 计算思维四步框架

信息科技课的核心思维训练，各环节对应：

| 计算思维要素 | 教学环节对应 | 教师提问示例 |
|-------------|-------------|-------------|
| **问题分解** | 问题分析阶段 | "这个问题可以拆成哪些小步骤？" |
| **模式识别** | 方案设计阶段 | "这个问题和之前做过的哪个任务类似？" |
| **抽象** | 方案设计阶段 | "哪些细节可以忽略？核心要素是什么？" |
| **算法设计** | 实践验证阶段 | "用流程图表示你的解决步骤。" |

### 课堂小测形式

- **代码阅读：** 给一段代码，预测输出结果
- **纠错题：** 给一个有 bug 的程序，找出并修正
- **概念填空：** 核心术语理解检测
- **流程图补全：** 补充缺少的步骤或判断条件
- **作品展示：** 完成指定功能的编程作品

### 注意事项

- **实践优先：** 操作/编程时间应不少于课时的 50%
- **编程梯度：** 半成品代码 → 完整程序 → 自主创作，逐步撤除支架
- **网络安全教育：** 贯穿所有学段，不只在"网络安全"专题课时才涉及
- **软硬件确认：** 课前确认编程环境/平台可用性，准备离线替代方案（无网络时的本地 IDE）
- **作品保存：** 提醒学生及时保存作品，预留保存时间
- **差异化：** 编程任务设置"必做+选做"，允许不同进度的学生有不同任务量

**文档结构：**
| id | audience | 内容 |
|----|----------|------|
| `lesson_plan` | 教师 | 上述环节 + 材料清单 + 代码/操作步骤 + 常见错误 + 调试策略 |
| `student_materials` | 学生 | 任务单 + 半成品代码 + 操作指南 + 步骤卡片 |
| `observation_template` | 教师 | 计算思维观察点 + 操作技能评价 + 课堂小测分类 |

**shared 常用注册内容：** 驱动问题、半成品代码、操作步骤、流程图模板、调试检查清单、评价量规。
