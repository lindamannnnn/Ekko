# 语文 — 课时教案模板

Loaded by `k12-lesson-planning` when the subject is **ela**（语文）.

## 澄清优先级（Step 1）

向教师确认时，按以下优先级询问缺失信息：

1. **年级 + 语文领域**（识字写字 / 阅读与鉴赏 / 表达与交流 / 梳理与探究 / 综合性学习）
2. **具体文本或主题**（古诗、散文、说明文、小说单元等）
3. **课标要求**（如果教师未提供，在 Step 2 从 `yuwen.md` 提取对应学段内容要求）

**默认值：**
- 未指定领域 → 阅读与鉴赏
- 未指定时长 → 40 分钟（小学）/ 45 分钟（初中/高中）
- 未指定学情 → 应用 UDL 中国默认值（句子支架 + 词汇表，见 `references/china.md`）

---

## 标准锚定

遵循 **SKILL.md 第二步——锚定课标**：使用 `references/curriculum/yuwen.md` 中的课标内容（核心素养、学习任务群、学段内容要求）作为标准的锚定来源。如果教师提供了地方性课程标准或校本标准，优先使用教师提供的标准。

**教材版本检测：** 检测教师是否提及教材版本（统编版/人教版/部编版）。如果已知，在输出中参考该版本的单元编排逻辑（仅用于举例风格，不加载教材数据）。

## 构建指引（Step 3）

语文课时通常包含以下环节，按课型弹性调整：

### 阅读课
| 环节 | 时间 | 教学活动 |
|------|------|----------|
| 导入/激趣 | 3-5 分钟 | 联系旧知或生活经验，激发阅读期待 |
| 初读感知 | 8-10 分钟 | 整体感知文本，解决字词障碍 |
| 精读品析 | 12-15 分钟 | 聚焦核心段落，品析语言、体会情感 |
| 拓展表达 | 8-10 分钟 | 读写结合或口语表达 |
| 小结作业 | 3-5 分钟 | 梳理收获，布置分层作业 |

### 写作课
| 环节 | 时间 | 教学活动 |
|------|------|----------|
| 情境导入 | 5 分钟 | 激活写作动机 |
| 范文引路 | 8-10 分钟 | 分析范文结构与方法 |
| 构思提纲 | 8-10 分钟 | 确定写作框架 |
| 当堂练写 | 12-15 分钟 | 片段或全文写作 |
| 分享修改 | 5-8 分钟 | 互评互改 |

### 识字写字课（1-2 年级）
| 环节 | 时间 | 教学活动 |
|------|------|----------|
| 情境识字 | 10 分钟 | 在语境中识记生字 |
| 字形分析 | 8-10 分钟 | 关注字形结构、书写要点 |
| 书写指导 | 10-12 分钟 | 描红、临写 |
| 拓展运用 | 5-8 分钟 | 组词、造句 |
| 小结检测 | 3-5 分钟 | 课堂小测 |

### 语文课特有注意事项
- 课文朗读贯穿各环节——范读、自由读、分角色读
- 字词教学在低年级占较大比重，高年级侧重篇章理解和表达
- 读写结合是语文课的核心策略——每节阅读课都应包含写的元素
- 课程思政自然融入——通过文本中的人物品质、家国情怀实现，不另贴标签
- **所有层级使用相同的年级水平文本。** 文本复杂度不调整——调整的是对文本的访问方式（脚手架帮助低层学生访问，高层学生独立分析）。这是语文教学的核心原则。

### 语文任务常用脚手架

| 语文任务类型 | 主要脚手架 |
|--------------|------------|
| 阅读理解（叙事） | 故事图：角色/问题/事件顺序/结局 |
| 阅读理解（说明性/信息性） | 主要观点 + 证据组织器 |
| 议论文写作 | 论点-理由-证据框架 |
| 记叙文写作 | 故事主线或结构化故事图 |
| 说明文写作 | 思维导图 → 段落框架 |
| 文本分析（作者手法、结构） | 注释引导 + "作者用______来______" 框架 |
| 比较/对比（文本或角色） | T 形图或维恩图 |

### 学情画像（默认值）

无诊断数据时按学段预设：

| 学段 | 常见瓶颈 | 应对策略 |
|------|----------|----------|
| 小学 1-2 年级 | 识字量不足 | 拼音/识字支持优先 |
| 小学 3-6 年级 | 阅读流畅性（识字准确率够但自动化低） | 朗读许可 + 伙伴阅读 + 理解脚手架 |
| 初中 7-9 年级 | 词汇和背景知识不足 | 学术词汇预教 + 语义支架 |
| 高中 10-12 年级 | 背景知识和分析策略不足 | 推理性理解框架 |

## lesson.json 映射

- `shared.subject`: `"语文"`
- `shared.domain`: 识字写字/阅读/写作/口语交际/综合性学习
- `shared.text_title`: 课文/文本标题

**文档结构：**
| id | audience | 内容 |
|----|----------|------|
| `lesson_plan` | 教师 | 上述环节 + 材料清单 + 板书 + 作业 + 常见错误 + 观察点 |
| `observation_template` | 教师 | 语文课堂观察点（朗读/理解/表达/书写）+ 课堂小测分类 |
| `student_materials` | 学生 | 按课型设计练习单，分层时用任务名区分层级 |

**shared 常用注册内容：** 核心问题、课文段落、字词清单、句式框架、写作评价量规、课堂小测。
