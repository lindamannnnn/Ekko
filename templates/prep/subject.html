关于 AI 模型

如何填写自定义 AI 通道

系统默认使用内置模型。如果你有自己的 OpenAI 兼容接口 KEY，填写后课评生成、课前备课、阶段总结等都会优先使用你的 KEY。

API KEY：你从模型服务商后台复制的密钥，常见前缀如 sk-...。不要泄露给他人。

接口地址：服务商提供的 OpenAI 兼容地址，必须包含 /v1 结尾。

模型名：你想调用的具体模型，请和服务商文档保持一致。

OpenAI 示例 接口地址=https://api.openai.com/v1，模型名=gpt-4o

智谱示例 接口地址=https://open.bigmodel.cn/api/paas/v4，模型名=glm-4-plus

DeepSeek 示例 接口地址=https://api.deepseek.com/v1，模型名=deepseek-chat

Kimi 示例 接口地址=https://api.moonshot.cn/v1，模型名=moonshot-v1-8k

若三项全部留空，则自动使用系统内置默认模型。

默认使用系统内置的弱模型（免费、速度快），能帮你搭出完整的教案、课件框架与课评， 但遇到复杂推理、跨学科整合或创意拓展时，可能会"泛泛而谈"，偶尔出现事实偏差。 如果你追求更稳的事实性和更强的教学设计，可以上传自己的强模型 API KEY。配置后课评生成与课前备课都会优先使用你的 KEY。
