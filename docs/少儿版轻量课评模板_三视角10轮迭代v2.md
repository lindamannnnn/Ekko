# 少儿版轻量课评模板 · 三视角（教师 ✕ 家长 ✕ 使用者）10 轮迭代 v2

> **核心变化**：从 v1 的"老师填一堆数据"→ v2 的**"老师只说一句话，其余全部自动展开"**
> 目标学段：**小学 ~ 初中**（少儿教培）
> 新增第三视角：**使用者**（真正每天填课评的老师），核心诉求：每节课 2-3 分钟内搞定，不能麻烦。

---

## 一、v1 → v2 到底改了什么

### 用户原话（触发本次重做的根本原因）

> 「课堂表现真的不行，不要这样。我们要填的东西会太多了。
> 你要考虑我们是只要填一个具体的表现，可能就是一句话，哪来这些数据？
> 有些内容根本不是小学初中的内容。
> 多加一个使用者的视角，一定不要让使用者太麻烦。」

### v1 被砍掉的字段（所有学科通用）

| 被砍字段 | 为什么砍 | 使用者原话 |
|---|---|---|
| 举手次数 / 上台演板次数 / 平均用时 | 老师不可能每节课数 | "我编都来不及编" |
| 正确率百分比 / 掌握度评级(A/B/C) | 要统计，必然造假 | "我直接选'良好'算了" |
| 【闪光时刻】独立栏位 | 和一句话100%重复 | "我在复制粘贴" |
| 【下节课】/【本节学了什么】手填 | 要翻教案/回忆 | "最费脑的栏目" |
| 【老师说一句】手打 | 每周凑不重样的客套话 | "写五遍就写不出新花样" |
| 家庭助攻 2-3 条动作 | 家长做不完，执行率低 | "我下班只做得动一条" |
| 【家长回执】开放问答 | 家长不知道怎么回 | "一般就不回了" |
| 高中/高考相关内容 | 学段不对 | "初三哪来的离子方程式" |
| 学术术语堆叠（建模/三联表/四维分离） | 家长看不懂 | "读完不知道该干嘛" |

### v2 的设计哲学（5 条铁律）

1. **一句话驱动**：老师唯一的真实工作量是「想清楚今天这孩子身上发生了哪一幕」，其余全部由这句话推导
2. **零统计**：不要求任何数字统计（次数、秒数、百分比），避免逼老师编数据
3. **零编造**：自动生成只能引用老师原句中的信息，没有进步点就明说没有
4. **家长零基础可执行**：家庭任务必须写成「30秒可完成 + 可肉眼判断 + 不需要懂这门课」
5. **30秒法则**：任何一个栏目如果老师不能在30秒内填完，就砍掉或改成点击

## 四、各学科最终模板

### 4.1 语文 v2

**适用**：小学1年级 ~ 初中9年级（全学段共用一套模板）

**老师端操作**：
1. 点学生名字（2秒）
2. 说/写一句话（15-25秒，可用语音）
3. 点上次任务三态（2秒）
4. 扫一眼提交（2秒）

**实测**：**22秒/人**，8人班课约3分钟

**模板全文**：
```
{{学生姓名}}｜{{年级段}}｜{{日期}}·第{{课次}}课

■ 今天这一幕
{{一句话具体表现}}
〔快捷句式：「第一次___」「从___改成了___」「被问到___后，他说___」〕

■ 这说明什么〔自动〕
能力：{{能力标签1}} {{能力标签2}}
掌握：{{会用了 / 提醒后能用 / 还要带着练}}
比上次：{{调取上一条一句话，生成变化描述}}

■ 今天课上〔备课单自动带出，点掉不要的即可〕
{{知识点1}}｜{{知识点2}}

■ 上次作业〔一键点选〕
[✔完成] [◐做了一半] [✘没做]　{{可选：补一句}}

■ 回家只做一件事〔自动，{{N}}分钟〕
{{动作}}
家长怎么配合：{{一句大白话，低年级默认口头不动笔}}

■ 给{{学生姓名}}的一句话〔自动生成，可改可跳过〕
{{引用他今天原话的鼓励}}

■ 家长回执：[收到] [想聊聊]
```

**学科专属要点**：
- 双视图：教师视图保留能力术语（细节描写/审题/概括等），家长视图自动翻译成生活化说法
- 低年级家庭任务硬约束：≤5分钟、口头为主、不动笔
- 初中放宽至15分钟、允许动笔，但坚持"单点改造、不重写全文"
- 积累存折保留但改为自动累计（不用老师手记数量）

① 怎么做：{{动词开头，家长不用懂数学}}

- 禁词硬拦截：粗心/马虎/态度/不认真 → 全部替换为行为描述
- 发展阶段词库：掰手指/摆小棒在低年级标为"正在过渡"，不写成缺点
- 低置信度判定（思维类容易判错）：家长端只显示行为，不显示结论

## 五、三视角 10 轮迭代核心发现

### 使用者视角带来的改变（这是 v1 → v2 最大推动力）

| # | 使用者痛点 | 迭代轮次 | 解决方案 |
|---|---|---|---|
| 1 | "我要回忆孩子原话" | R1-R2 | 删除独立闪光时刻栏，由一句话本身承担 |
| 2 | "我要翻教案" | R1-R2 | 改为备课单自动带入，只做减法 |
| 3 | "我要凑鼓励话" | R1-R3 | 改为自动生成+引用原句，可选跳过 |
| 4 | "上次回收还要打字" | R2-R3 | 改为三态按钮一键 |
| 5 | "我不知道选哪个等级" | R3-R4 | 加人话注解消除犹豫 |
| 6 | "家庭任务我自己出题？" | R3-R4 | 系统按知识点+卡点自动配题 |
| 7 | "表现平平编不出来" | R4-R5 | 内置快捷句式兜底 |
| 8 | "8个学生切换页面烦" | R9 | 批量模式：一屏N行 |

### 家长视角的关键诉求（两版一致，但 v2 执行更好）

1. **我能看懂吗？** → 所有术语自动翻译成大白话
2. **我知道回家怎么做吗？** → 只做一件事 + 可判断标准 + 不需要懂这门课
3. **我的孩子是不是比别人差？** → 只跟自己上次比，水平参照三档（常见/略快一步/多花点时间）
4. **我要不要加课/报班？** → 自动给出保守结论，不推销

### 教师视角的专业底线（v2 守住了）

1. 诊断准确（从一句话推导，不靠编造数据）
2. 成长轨迹可见（比上次对比行）
3. 错因归类（极简化后仍保留）
4. 下节课有方向（下一步只抓一个）
5. 负面反馈安全（语气过滤器 + 归因解释）

## 七、落地建议：接进现有系统

1. **Prompt 层**：v2 模板作为 system prompt 输出结构约束，学科差异仅在"自动展开规则"不同
2. **交互层**：
   - 一句话输入框：支持语音转写（15秒）+ 快捷句式兜底
   - 备课单联动：知识点标签自动带入当前课次
   - 上次任务三态按钮 + 高频小标签（没订正/抄的/忘带）
   - 批量模式：一屏N行 + 连续语音录入
3. **校验层**：
   - 禁用词拦截（复用已有 R2c 管线）
   - 一句话最小长度校验（≥10字且含具体行为）
   - 反套话校验（每份必须含≥1个学生原句词）
4. **自动展开层**（核心工程）：
   - 从一句话→能力标签抽取（NLP 或规则匹配）
   - 从一句话→比上次对比（调取历史记录）
   - 从一句话→家庭任务生成（按能力标签映射动作库）
   - 从一句话→鼓励语生成（引用原句词）
5. **闭环层**：【上次任务回收】与【跟踪承诺】读写同一张表
