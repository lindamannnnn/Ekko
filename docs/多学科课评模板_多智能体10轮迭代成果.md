# 多学科课评模板 · 多智能体 10 轮迭代成果

> 生成方式：5 个学科智能体（语文 / 数学 / 英语 / 物理 / 化学），每个学科内置「教师视角 Agent」与「家长视角 Agent」，
> 每轮由教师 Agent **填入具体学生的具体表现数据**生成完整课评 → 教师自评 → 家长挑刺 → 双方意见汇总修订模板，共 **10 轮 × 5 学科 = 50 轮迭代**。
> 前置调研：教培课后反馈黄金公式、四象限法、精简三段式、各学科课后辅导记录实例。

## 一、调研结论：不同学科的课评应该注重什么

| 学科 | 家长最想看到的 | 教师最容易写偏的 | 学科不可替代的观测点 |
|---|---|---|---|
| **语文** | 孩子"表达有没有变好"的可见证据 | 空谈"语感提升"、无作品对照 | 写作前后句子对照、积累量存折、阅读理解的思维路径 |
| **数学** | 到底哪一步卡住、怎么补 | 只说"计算粗心"，不做错因分类 | 错因六分类、三色掌握度、同类题正确率趋势 |
| **英语** | 敢不敢开口、能不能听懂 | 只报单词量，不报输出质量 | 听说读写四维分离、语音可听化证据、信心指数 |
| **物理** | 是"不理解"还是"不会算" | 把概念漏洞误判为计算失误 | 模型建立能力、受力/过程分析、生活现象锚点、实验安全 |
| **化学** | 记不住方程式怎么办 | 反复强调"背" | 宏观现象—微观本质—符号表征三联、实验安全、记忆策略而非记忆量 |

**共通结论（家长 Agent 在 10 轮中反复强调）**：

1. **结论要先行**——家长平均只给课评 30 秒注意力，必须有"速览行"。
2. **数字必须有参照系**——"正确率 70%"无意义，"70%（上次 55%，本阶段目标 85%）"才有意义。
3. **问题必须闭环**——只提问题不给"老师已经做了什么 + 家里做什么 + 下次怎么验证"，等于甩锅。
4. **家庭任务必须可执行**——写明"几分钟、谁陪、怎么判断做对了"，且家长零基础也能操作。
5. **表扬必须有证据**——"今天很棒"无效，"他自己说'原来这样想更快'"才有效。

## 二、10 轮迭代中最重要的 8 条共性改进

| # | 改进点 | 触发轮次 | 提出方 | 说明 |
|---|---|---|---|---|
| 1 | **30 秒速览 / 结论先行** | R2 | 家长 | 顶部三行摘要：本节内容 / 今日亮点 / 需跟进 + 家庭任务时长 |
| 2 | **精准诊断五段式闭环** | R3 | 教师 | 问题 → 真实成因 → 课上已干预 → 当堂验证结果 → B 方案（若仍不过关） |
| 3 | **数据强制带参照系 + 趋势曲线** | R4 | 家长 | 任何百分比必须标注"上次 / 阶段目标"，并附近三次同类指标 |
| 4 | **错因标准化编码，禁用"粗心"** | R4 | 教师 | 六类归因标签替代模糊词，家长才知道该练什么 |
| 5 | **家庭助攻三件事 + 避坑提示** | R5-R6 | 家长 | ≤N 分钟/天、零基础可执行、附"不要对孩子说的话" |
| 6 | **闪光时刻引用学生原话** | R6 | 家长 | 让家长感到"老师真的在看我的孩子"，情绪价值最高的一栏 |
| 7 | **家长回执 / 沟通闭环** | R8 | 家长 | 留答疑通道 + 承诺答复时效 + 一句"您最关心哪一点" |
| 8 | **学段与目标分层开关** | R9 | 教师 | 低年级具象版 / 初高中考点对标版；基础版 / 中档版 / 冲刺版 |

### 4.3 学科要点提醒

- 语文最忌"感觉化评语"。**每一条能力判断都必须挂一个作品证据**（原句、答案、原话）。
- 家长 Agent 在 R7 明确反馈：**积累存折是语文唯一能让家长感知"量变"的栏目**，务必保留累计数字。
- 低年级用"识字量 + 读句子流利度 + 看图说话"，初高中换成"文言实词 + 阅读答题规范 + 议论文结构"。

## 十一、落地建议：如何接进本系统

1. **Prompt 层**：把「跨学科通用母版 v11」作为 system prompt 的输出结构约束，学科专属诊断区按 `subject` 动态注入。
2. **字段层**：各学科 `final_template_fields` 可直接映射为课评表单字段，标 `*` 的为必填（速览、诊断区、家庭助攻、趋势）。
3. **校验层**：把「禁用词清单」做成生成后置校验器，命中即重写（已有 R2c 防编造模块可复用同一管线）。
4. **数据层**：趋势曲线依赖历史课评，取该生近三次同类指标；无历史时降级为"首次记录，下次起显示趋势"。
5. **分层层**：按 `grade` 自动选择低年级/初高中版本，按 `level` 选择基础/中档/冲刺版。
6. **闭环层**：【上次任务回收】与【跟踪承诺】需读写同一张表，形成跨课次闭环——这是本次迭代中家长信任度提升最大的单点改动。
