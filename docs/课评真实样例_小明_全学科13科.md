### 编程术语翻译对照表（发家长前强制翻译）

**编程课评三条硬规则**：

3. 家庭任务不能是"回家再写代码"（家长监督不了），只能是讲给家长听 / 画流程图 / 口述思路 / 改一个小地方

# 七、全局自检（13 份样例全部通过）

- **零统计数据**：无一处出现举手次数、正确率百分比、用时秒数、写了几页。唯一例外是编程的 OJ 通过题数——那是判题系统自动抓取的客观数据，非老师手填，且已翻译成大白话。
- **零禁用词**：无"粗心 / 马虎 / 态度 / 不认真 / 总是 / 永远"。
- **学段合规**：物理限初二起、化学限初三、生物限初一起、科学限小学中高年级，全部无高中内容。
- **家庭任务**：最短 3 分钟（数学）、最长 10 分钟，全部 ≤15 分钟，全部家长零基础可执行，全部只做一件事。
- **负面反馈**：每条都配了归因（"这不是笨/这是共性难点"）与出路，无单独甩问题。
- **鼓励语**：每条都引用了老师原句里的具体词，无"继续加油"类套话。
- **艺术类**：无打分、无"像不像"、无量化作业，主动化解天赋焦虑。
- **道法学科**：内容严格限于教材规范范围（公民基本权利、义务教育），表述中立客观。

# 八、艺术类课评禁语清单（书法/美术专用）

| 禁语 | 为什么不能说 | 替换写法 |
|---|---|---|
| "这幅画打7分" | 打分式评价杀死表达欲 | 评过程不评作品："你今天用了勾边再平涂的方法" |
| "画得不像 / 字不像样本" | 像不像从来不是目标 | "你观察到了XX细节""三横间距比上次舒服" |
| "画得不好看" | 主观审美否定，孩子不敢下笔 | "你用了自己的方式表达，这很珍贵" |
| "涂出界了 / 涂得乱" | 只盯缺点，否定探索 | "你在试不同笔触，下次可以先勾清形状再涂" |
| "没天赋 / 不是这块料" | 天赋论让孩子自我放弃 | "观察力和胆量都是能慢慢练出来的" |
| "别人都画完了你还没画完" | 横向比较伤自尊 | "你今天把角落的猫也画上了，比上次更完整" |
| "乱涂乱画" | 否定探索行为 | "你在尝试不同的笔触和颜色，这叫大胆表达" |
| "写得快就是写得好" | 误导家长，书法练的是控制力 | "书法比的是写得稳、写得清楚，急不得" |
| "比上次退步了" | 笼统否定，无出路 | "今天握笔比上次稳，收笔还可以再轻一点" |
