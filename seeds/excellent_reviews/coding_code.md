CSP01暑假集训（第1-5节） 课后小结

📅 2026-07-14 | 🏫 出勤：向子宁
🙋 请假：

📋 【本节课核心知识点】
1. 走进 C++：基本程序框架、变量声明与初始化、`cin`/`cout` 输入输出 - 必须默写
2. 整数运算：`+`、`-`、`*`、`/`、`%`、整数除法、取模运算、拆位 - 必须理解
3. 小数运算：`double` 类型、浮点数计算、精度控制、实际应用公式 - 必须理解
4. 单双路分支：`if`、`if-else`、关系运算符、奇偶判断、范围判断 - 必须理解
5. 多路分支：`if-else if-else`、多条件综合判断、闰年/成绩评级等问题 - 必须理解

⚠️ 【高频易错点】
• 整数除法直接截断小数，需要小数结果时要用 `double` 或 `1.0 * a / b`
• 取模运算 `%` 求的是余数，不是小数部分
• 拆位时 `% 10` 和 `/ 10` 的顺序容易搞反
• 条件判断中 `>=` 和 `>` 的边界值容易漏掉等于的情况
• `if-else if` 只执行第一个成立的分支，后续条件即使成立也不会执行
• 浮点数输出精度需要用 `fixed` 和 `setprecision` 控制
