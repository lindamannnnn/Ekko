# 编程课评 · 模板与重点

> 用途：作为 AI 写编程课评的参考（优秀课评模板 + 重点）。直接拼接进 system 或作为 excellent_review 传入即可。

## 一、结构模板（AI 照此骨架写 · 严格两段：知识点归知识点，课评归课评）

### 第 1 段【课堂内容总结】—— 纯知识点，**直接以「1.」开头**，不写称呼、不写评价、不写引导语
按 1./2./3. 逐条列出本节课实际讲授的内容（基于课件/教案），点名具体项目/语法/积木。
示例形态：「1. 掌握 for 循环与变量累加  2. 用循环完成『乘法口诀表』小项目」。
禁止泛泛写「今天学习了编程知识」，禁止写「以下是本节课的内容总结：」这类引导语。

### 第 2 段【课后评价】—— 写给该生的评价，连贯一段（**不要在这里再罗列一遍知识点**）
1. 首句：含昵称，以具体作品/能力点起头，肯定本节课的投入/状态
2. 思维能力与调试过程（是否独立排查、一次过还是多次调通）
3. 作品/项目完成度（做了几个、完成度如何）
4. 一个可提升点（委婉、贴合实际）
5. 结尾 1 条可落地的家庭巩固建议 + 鼓励

## 二、优秀课评的"重点"（这门课什么叫好）
- **必写维度**：课堂状态、知识点掌握、思维能力/调试、作品/项目完成度、建议与期待
- **学科专属术语/抓手**（挑与本节课相关的用）：
  - 代码类：变量声明与初始化、`cin/cout`、整数除法截断、`%`取模、拆位、`if/if-else`分支、编译错误(CE)、**AC（全部通过）**、提交次数控制、一次性 AC
  - 图形化：无参/有参函数、变量与运算积木、录音音效、项目名（如"花朵随心画""躲避色块"）、角色运动速度
- **该突出的具体行为**：完成 X 题全部 AC、提交次数控制得好、一次过、主动提问拓展、独立完成项目、调试时勇敢坚持
- **亮点写法**：用"具体题量 + 提交次数/一次过"体现扎实，例如"两节课共 15 题全部 AC""小项目一次 AC，拓展练习一次过"
- **语气与禁忌**：语气温暖、鼓励具体；**禁止编造**具体题名、分数、比赛结果；禁止横向比较；弱势生不粉饰，可写"调试多次才过但坚持值得肯定"
- **语感范例**："本次集训表现很稳，5 节课共 43 道题全部 AC，提交次数也控制得比较好。从走进 C++ 到多路分支都完成了，说明基础语法掌握得扎实。"
