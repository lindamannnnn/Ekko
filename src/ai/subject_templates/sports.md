# 体育课评 · 模板与重点

> 用途：作为 AI 写体育课评的参考（优秀课评模板 + 重点）。直接拼接进 system 或作为 excellent_review 传入即可。

## 一、结构模板（AI 照此骨架写 · 严格两段：知识点归知识点，课评归课评）

### 第 1 段【课堂内容总结】—— 纯知识点，**直接以「1.」开头**，不写称呼、不写评价、不写引导语
按 1./2./3. 逐条列出本节课主要学习与强化的内容（基于课件/教案），点名具体项目/技能。
示例形态：「1. 学习跳绳的双脚交替跳  2. 强化体能耐力」。
不要泛泛，禁止写「以下是本节课的内容总结：」这类引导语。

### 第 2 段【课后评价】—— 写给该生的评价，连贯一段（**不要在这里再罗列一遍知识点**）
1. 首句：含昵称，以具体项目/技术动作起头，肯定本节课的投入与素质提升
2. 技能掌握档位（三选一写清）：
   - 已全部掌握，回去巩固即可
   - 掌握了其中 XX 方面，在 XX、XX 方面还有不足，需再练
   - 掌握了 XX，在 XX、XX 方面做得很好，值得表扬
3. 运动态度/天赋 或 集体表现（帮助同学等）
4. 结尾 1 条家庭练习建议 + 鼓励

## 二、优秀课评的"重点"（这门课什么叫好）
- **必写维度**：课程内容回顾、技能掌握程度、运动态度/天赋、建议
- **学科专属术语/抓手**：跑/跳/投、运动技能掌握与灵活运用、运动天赋、刻苦练习、动作技巧、集体主义、帮助薄弱同学
- **该突出的具体行为**：认真听讲刻苦练习、不怕苦不怕累、全部掌握/部分掌握、主动帮助体育薄弱的同学一起进步
- **亮点写法**：用"掌握档位"清晰分层评价；鼓励型收尾（"铁杵磨成针"）；点名帮助同学的表现
- **语气与禁忌**：**禁止绝对化用词**（"最出色""最"等，触发 R2a 防投诉）；**禁止横向比较**；用"掌握其中 X 方面、在 X 方面还有不足"客观分层，不夸大
- **语感范例**："XX 学生在课上学习了 XX 技能，掌握了其中跑、跳方面，在投的发力方面还有很多不足，回家还要再琢磨技巧多练习。天分不同，你的点滴进步老师都看在眼里，只要功夫深，铁杵磨成针，加油！"
